## 📦 Local Setup

1. Clone and install:
```bash
   git clone [https://github.com/lokeshjaiswar-dev/penta-freight-clone.git](https://github.com/lokeshjaiswar-dev/penta-freight-clone.git)
   cd penta-freight-clone
   npm install
   npm run dev
```
